# Mutation testing of the trusted contract: one control module at a time (`--targets`, `--every`)

Targets: the `rel-*` mutants against `RecursionFast.Controls.Relation`; `ext-computes-small-domain`,
`ext-computes-short-queries`, `ext-computes-short-tape` and `ext-progcap-2^21` against
`RecursionFast.Controls.Extractor`; `ext-tape-no-log` against `RecursionFast.Controls.MaskedLeaf`. The
build of a target includes the library modules it imports: a kill by one of them means that the
mutant is caught before the control is reached, not that the control alone misses it.

Generated by `python3 -I tests/mutation/run.py` (`tests/mutation/README.md`); do not edit by hand.
Mutants: `tests/mutation/mutants.toml`. A mutant is KILLED by the first module whose build fails
(stage `proofs`: the library and the controls) or by an organiser test (stage `harness`), INVALID
if the contract itself no longer compiles, SURVIVED otherwise. An accepted survivor's reason, and a
note on a mutant whose kill or invalidity is worth explaining, are in `tests/mutation/accepted.toml`.
